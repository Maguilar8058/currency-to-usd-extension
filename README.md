# Currency to USD Price Converter

Cross-browser extension for Firefox, Chrome, and Edge. It detects prices in different currencies and displays their USD equivalent next to the original price.

## Installation

- Firefox: open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select the root `manifest.json`.
- Chrome/Edge: open the extensions page, enable **Developer mode**, choose **Load unpacked**, and select the `chrome-edge` folder.
